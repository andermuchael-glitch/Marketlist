# Supabase — Marketlist

A dependência do cliente Supabase Kotlin e o banco inicial já estão preparados.

1. Crie um projeto no Supabase.
2. Execute supabase/schema.sql no SQL Editor.
3. Configure URL e Publishable Key no build do Android.
4. Ative autenticação quando quiser listas separadas por usuário.
5. Crie políticas RLS ligadas ao usuário antes de liberar escrita em produção.

A primeira versão do APK funciona localmente para testes. A sincronização em nuvem será ligada na próxima etapa sem mudar a interface.
